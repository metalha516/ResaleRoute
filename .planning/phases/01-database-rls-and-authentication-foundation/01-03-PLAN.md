3. `public.process_order_and_split(p_item_id UUID, p_idempotency_key TEXT) RETURNS UUID`:

   - Lock `items` with `SELECT * INTO v_item FROM public.items WHERE id = p_item_id FOR UPDATE NOWAIT;` (if lock contention occurs, PostgreSQL raises `lock_not_available` SQLSTATE `55P03` immediately).

4. `public.open_return_dispute(p_order_id UUID, p_reason TEXT, p_evidence_urls TEXT[]) RETURNS UUID`:

   - Append chained `DISPUTE_OPENED` row into `provenance_events`. Return `v_dispute_id`.

5. `public.resolve_dispute(p_dispute_id UUID, p_resolution dispute_status, p_resolution_notes TEXT) RETURNS VOID`:
   - Verify `(auth.jwt() -> 'app_metadata' ->> 'role') = 'boutique_owner'` and `p_resolution IN ('denied_closed', 'approved_refund')`.

   - If `p_resolution = 'approved_refund'`: update `items` (`status = 'refunded_relisted'`, `listed_at = v_now`, `sold_at = NULL`); append chained `RETURN_ACCEPTED_RELISTED` row into `provenance_events`.

6. `public.settle_expired_escrows() RETURNS INTEGER`:
   - Find all `orders` joined with `items` where `items.status = 'sold_escrow'`, `orders.return_window_expires_at < v_now`, and `NOT EXISTS (SELECT 1 FROM public.disputes d WHERE d.order_id = orders.id)`.
