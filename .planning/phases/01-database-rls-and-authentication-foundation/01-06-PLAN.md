| `redirectUrl` Query Parameter -> GoRouter Navigation | Untrusted query string on `/login?redirectUrl=...` could cause open redirects |
| Client Route Guards -> UI Presentation | UI route guards protect UX navigation across 5 roles, backed by PostgreSQL RLS & RPC guards |
| Login Form -> Supabase Auth | Repeated taps or verbose errors could leak account state or trigger duplicate auth calls |
